# Carwash OS module map

- `src/carwash/App.jsx` — OshaHub landing, Supabase sign-in, registration review and operations UI.
- `src/carwash/model.js` — local demo seed and tolerant browser-state migration.
- `src/carwash/carwash.css` — responsive role workspaces, landing page, PWA/mobile and recovery screens.
- `src/components/ErrorBoundary.jsx` — non-destructive render recovery and development diagnostics.
- `src/services/supabaseBrowser.js` — Supabase browser client.
- `database/carwash.sql` — PostgreSQL tenant schema and secured onboarding/workflow RPCs.
- `public/` — OshaHub logo, icon, favicon, manifest and offline app shell.
- `native-apps/washer/` — washer mobile app prototype.
