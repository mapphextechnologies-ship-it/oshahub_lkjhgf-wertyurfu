Salama Lock

Device lock middleware

API gateway for finance partners to register devices and queue remote lock / unlock commands via Google DLC.

  • GET/api/v1/devices
  • GET/api/v1/devices/{lockId}
  • GET/api/v1/devices/by-imei/{imei}
  • DELETE/api/v1/devices/{id}
  • POST/api/v1/lock
  • POST/api/v1/unlock
  • GET/api/v1/commands/{id}
  • GET/api/v1/monitoring/queue

Issue a partner key in the browser: Admin → Issue API key. Partners then send X-Api-Key: <key> on API requests.
