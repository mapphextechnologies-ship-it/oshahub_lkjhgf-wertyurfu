What Salama Lock does

Salama Lock is a device-lock middleware for finance/retail partners. Partners authenticate with API keys (or JWT), register devices, and enqueue lock/unlock commands. A scheduled queue worker claims commands and executes them through a provider (MockGoogleProvider today; GoogleDlcProvider is a stub).

Identity model (critical)

  • External device identity: permanent lockId of form SL-<ULID> (generated by LockIdGenerator).
  • Internal UUID (devices.id) is never serialized to partners (@JsonIgnore on DeviceResponse.id).
  • IMEIs and Google IDs live in device_identifiers; devices.imei is denormalized primary IMEI for legacy/admin.
  • Lock/unlock preferred key is lockId. IMEI fallback exists only while salama.identity.allow-imei-lock=true.

Default scopes on new API keys

devices:read,devices:write,commands:write,commands:read

Local quick start

docker compose up -d
./mvnw spring-boot:run

# Create company + API key (requires X-Admin-Key in non-open admin mode)
curl -s -X POST http://localhost:8080/api/v1/admin/companies \
  -H 'Content-Type: application/json' \
  -H 'X-Admin-Key: salama-local-admin' \
  -d '{"name":"Acme Finance","code":"ACME","contactEmail":"ops@acme.test"}'
