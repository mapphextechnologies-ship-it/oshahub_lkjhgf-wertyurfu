HTTP surface

API Reference

Every HTTP endpoint discovered in Spring controllers. Auth, scopes, bodies, and status codes match the current code.

Conventions

  • Base URL (local): http://localhost:8080
  • Partner auth: X-Api-Key: sk_live_… or Authorization: Bearer <jwt>
  • Admin auth: X-Admin-Key (required when configured)
  • Callback auth: X-Callback-Secret (required when configured)
  • Correlation: optional request header X-Correlation-Id; always echoed on responses for audited paths
  • Error body shape: ApiError via GlobalExceptionHandler (see Error Reference below)
  • Method security authorities use prefix SCOPE_ (e.g. scope devices:read → authority SCOPE_devices:read)

Monitoring (partner-authenticated)

No @PreAuthorize scope checks — any authenticated partner principal can call these.

  • GET /api/v1/monitoring/statistics → devicesTotal, commandsByStatus, pendingCallbacks
  • GET /api/v1/monitoring/provider → activeProvider, configuredProvider
  • GET /api/v1/monitoring/queue → pending/retrying/processing counts, enabled flag
These return global counts (not company-scoped) because repositories use aggregate count().
